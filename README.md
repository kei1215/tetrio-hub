# tetrio-hub

TETR.IO 関連をまとめるリポジトリ(GitHub Pages: `/docs`)。

- `docs/spin/` : 盤面回転のスクリプト
- `docs/counter/` : スピンカウンター本体(SPIN・T-SPIN・QUAD の回数。表示だけ。リプレイ盤面修正のブックマークから起動)
- `docs/replay-edit/` : リプレイ盤面修正(リプレイを止めるとその場面から操作できる。再生で元に戻る)
- `docs/patch/` : オフラインパッチ(Linux / Mac / Windows)
- `docs/bookmarklets/` : ブックマークレット各種
- `import-from-old-site.sh` : 旧サイトからのコピー用(旧サイトは読むだけ)

盤面回転は見た目だけを変えます。リプレイ盤面修正はリプレイの中だけで動き、再生すると止めた場面に戻します(火力は相手に送りません)。どちらも、対戦中のゲームの判定や、ほかの人の画面には影響しません。
ページの見た目は Kei's HomePages(Start Bootstrap "Clean Blog", MIT)に合わせています。
