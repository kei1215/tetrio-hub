### リプレイ → MP4 ツール(開発要件 6章 / 最優先)
できていること:
- tetr.io 上で動くブックマークレットで、`.ttr` / `.ttrm` から 1080p の MP4 を作れる(公開済み)。
- 再生は入力の記録からの再計算(MIT ライセンスのエンジンを使用)。TL はほぼ全ラウンドで元の試合と一致。
- QP(ソロ)は、結果が元の試合と完全に一致。mod(allspin_reversed)付きも一致。
- 画面には進み具合だけを出し、裏で描いて書き出す。1ラウンド 23.8 秒の動画を約 8.2 秒で生成できる。

## 5. 今の公開状態

- **デスクトップ版パッチ**:最新は v4.8255(2026-11-10 の TETR.IO 更新に対応済み)。
  - Mac / Windows / Linux × vA / vO / vR。
  - CONFIG の「PATCH UPDATE」から更新できる。
  - vA・vO には、別に TETRIO-Resources-1.0.zip(TETR.IO の素材。Discord で配布)が必要。

  - 盤面回転:回転入れのときだけ盤面を回すブックマークレット
  - リプレイ盤面修正:リプレイを止めて、その場面から操作できるブックマークレット。スピンカウンター付き
  - QP OFFLINE:オフライン版のブックマークレット(30日キャッシュ)
  - パッチのダウンロード、機能基準書、ミッションエディタ
- **注意**:TETR.IO の本体が更新されると、パッチもブラウザ版 QP OFFLINE も合わなくなることがあります。直し方は、リポジトリの `tools/patch/CLIENT-UPDATES.md` にまとめてあります。
