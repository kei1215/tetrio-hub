TETR.IO スピンカウンター

ほかのツールとは別のブックマークレットです。公式の https://tetr.io/ で、盤面ごとにスピン・T-spin・QUAD の回数を数えて表示します。表示だけで、ゲームの判定や、ほかの人の画面には影響しません。

登録

下のボタンをブックマークバーへドラッグしてください(このページでクリックしても動きません)。

スピンカウンター

上が動かないときの代替: スピンカウンター(fetch版)

使い方(PC)

  1. https://tetr.io/ を開き、ゲームを始める前(リプレイを開く前)にブックマークをクリックします。右上に「スピンカウンター」のパネルが出ます。
  2. ゲームを始めると数え始めます。SOLO・QP・TL・ルーム・観戦・リプレイで使えます。押したあとに始まったゲーム・開いたリプレイが対象です。
SPINスピンの回数(T 以外のミノ・MINI も含む)。かっこ内は MINI の数
SPIN の列ごとスピンで消したライン数ごとの内訳(0列 / 1列 / 2列 / 3列)。パネルのボタンで表示/非表示
ミノごとスピンをミノの種類ごとに(T・S・Z・L・J・I・O)。パネルのボタンで表示/非表示
T-SPINT-spin の回数(MINI 含む) / 置いた T ミノの数と、その割合。MINI の数も出します
QUAD4ライン消しの回数
  • 2人以上のときは、画面の左の盤面から順に並びます。
  • リプレイで前に戻すと、その先の分は数え直します。先へ大きく飛ばしたときは、回数だけまとめて足します(そのあいだの T ミノの数は入りません)。
  • リプレイ盤面修正で操作した分は、再生して元に戻すと消えます。
  • ブックマークを押し直しても、数えた回数は消えません。パネルを閉じると右上の小さな「カウンター」ボタンになり、押すと開きます。

更新は自動です。30秒ごとに新しい版を確かめ、出ていれば読み込み直します。

数え方: ゲームが1フレーム進むたびに、TETR.IO 自身の集計(スピンの回数・消去の種類・置いたミノの数)の増え方を読んでいます。

手動コピー用

本体: tetrio-spin-counter.js(開発者ツールのコンソールに貼っても動きます)
