リプレイ → MP4 変換

公式の https://tetr.io/ で、リプレイファイル(.ttr / .ttrm)を 1080p の MP4 動画にします。リプレイの入力からゲームを計算し直し、TETR.IO の画像・音を使って裏で描画します。画面には進み具合だけが出ます。

ファイルはどこにも送りません(読み込み・変換・保存はすべてブラウザの中です)。TETR.IO の画像・音楽・効果音は、実行時に tetr.io から読み込みます。

コードを手動でコピーする

使い方(PC)

  1. https://tetr.io/ を開き、ブックマークをクリックします。右下に「リプレイ → MP4」のパネルが出ます。
  2. 「リプレイを選ぶ」で .ttr / .ttrm を選びます。
  3. ラウンド(全ラウンド/1ラウンドだけ)、フレームレート(60 / 30fps)、画質を選んで「MP4 を作る」を押します。
  4. 2人対戦では「開始演出(TR)」「点数演出(TL の長さ)」を選べます。点数演出なしのときは「ラウンド間 ○ 秒」で間隔を決められます。「盤面の揺れ(設置・回転)」を外すと、盤面が揺れなくなります。「stats 表示」を外すと、盤面の横の数値(TIME・ATTACK・PIECES・VS など)を出しません。「右側」でどちらのプレイヤーを右に置くかを選べます(盤面・上の点数・TL の演出がそろって入れ替わります)。「カウントダウン」がオンのときは、各ラウンドで盤面が降りてきてから 3・2・1・GO で始まります。「効果音」で、2人の音を左右に分けるか、両方から聞こえるようにするかを選べます(QP はカウントダウンなし・音は常に両方から)。
  5. 終わったら「MP4 を保存」で保存します。保存しないままページを閉じると消えます。
  • 変換中も TETR.IO の画面はそのままです。タブを閉じたりリロードしたりすると中止になります。
  • 見た目は ULTRA 相当の固定設定です(自分の TETR.IO の設定は読み取るだけで、書き換えません)。
  • Chrome / Edge などの WebCodecs(動画エンコード)に対応したブラウザで使ってください。

対応しているリプレイ

  • TETRA LEAGUE・ルーム対戦(.ttrm)、40L・BLITZ など(.ttr)。
  • QUICK PLAY(ZENITH)。MOD 付き(リバース MOD を含む)も計算できます。DUO は一部だけの対応です。
  • QP は QP 用の盤面スキン・高度メーター・予告ゴミのメーターで描き、背景は通常プレイと同じ塔の絵が高度に合わせて動きます(開始時は少し上から降りてきます)。BGM も本体と同じく階層ごとに切り替わります(HYPERSPEED の曲は MOD なしのときだけ)。

TL の演出

  • 開始演出:GET READY・青/赤のカード・VS・FT。TR・ランク・順位(100位以内のみ。1位は紫、10位以内は金、100位以内は銀)は、TETRA CHANNEL から試合のときの値を取ります(見つからないときは今の値)。その人の TL 平均(APM・PPS・VS)もカードに出します。
  • 点数演出:ラウンドが決まった 1.5 秒後から 5 秒、点数が上がる画面(MATCH POINT・TIEBREAKER 付き)。ラウンドの間隔は TL と同じです。
