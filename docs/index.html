TETR.IO tools

個人用ツールです。対戦中のゲームの判定や、ほかの人の画面には影響しません(リプレイ盤面修正はリプレイの中だけで動きます)。ゲームの更新で動かなくなることがあります。

盤面回転

回転入れの判定が出たときだけ、その向きへ盤面を回すブックマークレット(中心はプレイ範囲の真ん中)

SOLO・リプレイ・ルームで使えます。2人以上のときは「それぞれ回す/まとめて回す」を選べます。

リプレイ盤面修正

リプレイを止めると、その場面から自分で操作できるブックマークレット(再生すると元に戻る)

火力は表示だけで相手には送りません。fumen 書き出し・2人の左右入れ替え・スピンカウンター(SPIN・T-SPIN・QUAD)付き。

QP OFFLINE

tetr.io 上で、別タブに OFFLINE 版を起動するブックマークレット

QP・ZEN・ローカル/オンラインリプレイ・端末内保存・OFFLINE 盤面回転。デスクトップ版パッチもこちら。
