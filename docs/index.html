TETR.IO tools

公式の TETR.IO で使う、個人用のブックマークレットとデスクトップ版パッチです。

対戦中のゲームの判定や、ほかの人の画面には影響しません(盤面修正はリプレイの中だけで動きます)。ゲームの更新で動かなくなることがあります。

盤面回転

回転入れの判定が出たときだけ、その向きへ盤面を回すブックマークレット(中心はプレイ範囲の真ん中)。

SOLO・リプレイ・ルームで使えます。2人以上は「それぞれ回す/まとめて回す」を選べます。

リプレイ盤面修正

リプレイを止めると、その場面から自分で操作できるブックマークレット(再生すると元に戻る)。

火力は表示だけで相手に送りません。fumen 書き出し・2人の左右入れ替え・スピンカウンター付き。

QP OFFLINE

TETR.IO 上で、別タブに OFFLINE 版を起動するブックマークレット(30日キャッシュ版)。

QP・ZEN・ローカルリプレイ・端末内保存。

デスクトップ版パッチ

Mac・Windows・Linux の TETR.IO に入れるパッチ v4.8243(O形式・R形式・A形式)。
