QP DUO リプレイ保存

公式の https://tetr.io/ で、QUICK PLAY の DUO が終わったとき、自分のリプレイ(.ttr)を保存します(相方の分は今後対応)。

リプレイはこの端末の中だけに保存し、どこにも送りません。デスクトップ版パッチ(v4.8257 以降)には最初から入っています(CONFIG > QP PATCH TOOLS > QP DUO REPLAYS)。

登録

下のボタンをブックマークバーへドラッグしてください(このページでクリックしても動きません)。

DUO保存

コードを手動でコピーする

使い方

  1. https://tetr.io/ を開いたら、DUO を始める前にブックマークをクリックします(右下に一覧が出ます。× で閉じて構いません)。ページを読み込み直したら、もう一度クリックしてください。
  2. DUO が終わると、右下に「QP DUO: 自分のリプレイを保存しました」と出ます。↓ TTR を押すと、普通のリプレイと同じようにダウンロードできます(保存先は自分で選べます)。
  3. 押し忘れても、この端末の中に控えが残ります(新しい順に 50 件まで)。ブックマークをもう一度クリックするか、パッチ版では CONFIG > QP PATCH TOOLS > QP DUO REPLAYS で一覧が出て、あとからダウンロード・削除できます。
  4. 2人分をまとめる:自分と相方がそれぞれ保存した .ttr を集め、一覧の「2人の TTR を合成」で2つ選ぶと、1つの .ttrm になります(同じ DUO のものだけ。シード・名前で確かめます)。開くと2人の盤面が並んで再生されます。
  5. うまく保存できないときは、一覧の「診断ログ ↓」で記録を JSON に出力してください(自動では送りません)。
  • 保存した .ttr は、TETR.IO のリプレイとして開けます。
  • 同じプレイは 1 回だけ保存します。
  • ブラウザのサイトデータを消すと、端末内の控えも消えます。
