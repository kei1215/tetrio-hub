TETR.IO 盤面回転

QP OFFLINE とは別のブックマークレットです。公式の https://tetr.io/ で、盤面の見た目だけを回します。回転の中心は、いつもプレイ範囲(横10×縦20)の真ん中です。ゲームの判定や、ほかの人の画面には影響しません。

登録

下のボタンをブックマークバーへドラッグしてください(このページでクリックしても動きません)。

上が動かないときの代替: 盤面回転(fetch版)

使い方(PC)

  1. https://tetr.io/ を開き、ブックマークをクリックします。メニュー画面でも、リプレイやルームの中でも押せます。
  2. 左下に操作パネルが出ます。
  3. 盤面はふだんは回りません。回転入れ(T-spin など)の判定が出たときだけ、その向きへ決まった角度だけ回ります。パネルの「盤面: 2」のような数字が、対象の盤面の数です。

15秒たってもパネルが出ないときは、ページを再読み込みしてからもう一度押してください。

更新は自動です。動いている間、30秒ごとに新しい版が出ていないか確かめ、出ていれば設定をそのままに読み込み直して再実行します(パネルに「最新版に更新しました」と出ます)。ブックマークを押し直しても、最新版で起動し直してパネルが開きます。

2人以上のとき(リプレイ・ルーム)

パネルのボタンで切り替えます。

2人以上: それぞれ回す盤面ごとに、自分のプレイ範囲の中心で回ります。盤面の位置は動きません
2人以上: まとめて回す全員の盤面の中心を真ん中にして、盤面ごと一緒に回ります(180°で左右が入れ替わる)

回転入れのときだけ回す(最初の設定)

  • ミノを置いたときに、ゲームが回転入れ(スピン)と判定したときだけ、盤面を「スピン1回の角度」(最初は 90°)だけ回します。盤面に「T-spin」「MINI S-spin」などと出るときで、T 以外のミノや MINI も対象です。ふつうの回転や、スピンの形にしてから動かして置いた場合は回りません。
  • 回す向きは、その回転入れの最後の回転の向きだけで決めます。左回転で入れれば左、右回転で入れれば右へ回ります(それまでの回数による重み付けはしません)。
  • 180°回転の回転入れでは、盤面を 180°(パネルで 360° に切り替え可)回します。向きは毎回交互(右 → 左 → 右 …)です。180°回転かどうかは、直前に押した 180°回転のキーで見分けます(観戦中はキー入力がないので、ふつうの回転入れとして扱います)。

判定は、ゲームが盤面に出す「◯-spin」の表示で読み取ります。向きは、スピンになった回転のときにゲームが盤面を少し傾ける向きで決めます(傾きが見えないときだけ、直前の回転キー)。効果音の音量は関係ありません。読むだけで、ゲームの入力・判定は変えません。

操作パネル

回転: スピン判定のときだけ / ずっと回す押すたびに切り替わります。「ずっと回す」は、一定の速さで回り続けます
スピン1回の角度ふつうの回転入れ1回で回す角度(15°〜180°)
180°回転の回転入れ: 180° / 360°180°回転で入れたときに回す角度。押すたびに切り替わります。向きは毎回交互
秒/周「ずっと回す」のときの、1回転にかかる秒数(2〜120)
固定角度動かすとその角度で止まります。「固定角度を解除」で回転に戻ります
回転 ON/OFF回転の停止/再開
逆回転(ずっと回すとき)「ずっと回す」の向きを反転します
角度を0に戻すまっすぐの向きに戻します
中心の目印 ON/OFF回転の中心の赤い点の表示
パネルを閉じるパネルが左下の小さな「盤面回転」ボタンになります(回転は続きます)。ボタンを押すと開きます。止めるときはページを再読み込み

iPhone/iPad(Safari)・Android(Chrome)

  1. このページを普通のブックマークとして保存し、名前を「盤面回転」にします。
  2. 「ブックマークコードをコピー」を押し、保存したブックマークの URL を全部消してコードを貼り付けます。
  3. https://tetr.io/ を開き、Safari はブックマーク一覧から、Android Chrome はアドレスバーに「盤面回転」と入力して候補から実行します。
