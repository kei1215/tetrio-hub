TETR.IO 盤面回転

QP OFFLINE とは別のブックマークレットです。公式の https://tetr.io/ で、盤面の見た目だけを回します。回転の中心は、いつもプレイ範囲(横10×縦20)の真ん中です。ゲームの判定や、ほかの人の画面には影響しません。

登録

下のボタンをブックマークバーへドラッグしてください(このページでクリックしても動きません)。

盤面回転

上が動かないときの代替: 盤面回転(fetch版)

使い方(PC)

  1. https://tetr.io/ を開き、ブックマークをクリックします。メニュー画面でも、リプレイやルームの中でも押せます。
  2. 左下に操作パネルが出ます。
  3. SOLO(40L・BLITZ・ZEN など)、リプレイ、ルームで盤面が出ると回り始めます。パネルの「盤面: 2」のような数字が、回している盤面の数です。

15秒たってもパネルが出ないときは、ページを再読み込みしてからもう一度押してください。

2人以上のとき(リプレイ・ルーム)

パネルのボタンで切り替えます。

2人以上: それぞれ回す盤面ごとに、自分のプレイ範囲の中心で回ります。盤面の位置は動きません
2人以上: まとめて回す全員の盤面の中心を真ん中にして、盤面ごと一緒に回ります(180°で左右が入れ替わる)

回転入力に合わせて回す

TETR.IO の「CONTROLS」のキー設定(GUIDELINE・WASD・CUSTOM、ゲームパッドも)をそのまま読み取ります。キーの入力は見るだけで、ゲームに届く入力を止めたり変えたりはしません。180°回転は数えません。

数えるのは自分のキー入力なので、リプレイやほかの人の盤面では、向きは最後に決まったままになります。

操作パネル

秒/周1回転にかかる秒数(2〜120)
固定角度動かすとその角度で止まります。「固定角度を解除」で回転に戻ります
回転 ON/OFF・逆回転回転の停止/再開、向きの反転
向き: 回転入力に合わせる直近20回の回転入力で、左回転が多ければ左、右回転が多ければ右へ回ります(同数なら今の向きのまま)。パネルに「左◯/右◯」が出ます。もう一度押すと「固定」に戻ります
角度を0に戻すまっすぐの向きに戻します
中心の目印 ON/OFF回転の中心の赤い点の表示
パネルを閉じるパネルだけ消えます(回転は続きます)。止めるときはページを再読み込み

iPhone/iPad(Safari)・Android(Chrome)

  1. このページを普通のブックマークとして保存し、名前を「盤面回転」にします。
  2. 「ブックマークコードをコピー」を押し、保存したブックマークの URL を全部消してコードを貼り付けます。
  3. https://tetr.io/ を開き、Safari はブックマーク一覧から、Android Chrome はアドレスバーに「盤面回転」と入力して候補から実行します。
