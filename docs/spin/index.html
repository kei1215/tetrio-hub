TETR.IO 盤面回転

QP OFFLINE とは別のブックマークレットです。公式の https://tetr.io/ の SOLO・リプレイで、盤面の見た目だけを回転させます。対戦(QP・リーグ・ルーム)では使わないでください。

登録

下のボタンをブックマークバーへドラッグしてください(このページでクリックしても動きません)。

盤面回転

上が動かないときの代替: 盤面回転(fetch版)

使い方(PC)

  1. https://tetr.io/ を開き、メニュー画面のままブックマークをクリックします。
  2. コンソールに [spin] waiting for the next frame... と出て、画面が描画された瞬間に左下へ操作パネルが出ます。
  3. SOLO(40L・BLITZ・ZEN など)やリプレイを始めると、盤面が回ります。

15秒以内にゲーム画面をつかめなかったときは、コンソールに could not capture the app within 15s と出ます。ページを再読み込みしてからもう一度押してください。

操作パネル

秒/周1回転にかかる秒数(2〜120)
X補正 / Y補正回転の中心をずらします
固定角度動かすとその角度で止まります。「固定角度を解除」で回転に戻ります
回転 ON/OFF・逆回転回転の停止/再開、向きの反転
中心をクリックで指定押したあと、回転の中心にしたい場所(盤面の真ん中など)をクリックします。Esc で中止
中心を自動に戻すクリックで指定した中心をやめ、盤面まわり全体の中心に戻します
中心の目印 ON/OFF回転中心の赤い点の表示。中心がずれていないか確かめるのに使います
パネルを閉じるパネルだけ消えます(回転は続きます)。止めるときはページを再読み込み

iPhone/iPad(Safari)・Android(Chrome)

  1. このページを普通のブックマークとして保存し、名前を「盤面回転」にします。
  2. 「ブックマークコードをコピー」を押し、保存したブックマークの URL を全部消してコードを貼り付けます。
  3. https://tetr.io/ を開き、Safari はブックマーク一覧から、Android Chrome はアドレスバーに「盤面回転」と入力して候補から実行します。

手動コピー用

本体: tetrio-spin-console.js(開発者ツールのコンソールに貼っても動きます)
