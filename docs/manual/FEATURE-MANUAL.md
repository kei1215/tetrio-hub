# TETR.IO Patch・TETR.IO tools 機能説明書

最新版:デスクトップ版パッチ v4.8281(A / R / O)、ブラウザ版 QP OFFLINE v4.8241、ミッションエディタ v6.5

これまでに追加した機能を、まとめて説明します。【 】の中は、その機能が入った版や日付です。分かっているものだけを書き、分からないものは書いていません。

## 1. 配布物の種類

| 種類 | 内容 |
|---|---|
| デスクトップ版 **O**(OFFLINE) | オフラインの QP やソロなど+リプレイの機能。TETRIO-Resources-1.0.zip(TETR.IO の素材。Discord で配布)が必要 |
| デスクトップ版 **R**(Replay) | リプレイの機能だけ。オフライン機能・AI は入らない。素材 zip は不要 |
| デスクトップ版 **A**(AI) | O の内容+AI。素材 zip が必要。ダウンロードには Discord ログインとサーバーのロールが必要【サイト:2026-11-09】 |
| ブラウザ版 QP OFFLINE | tetr.io 上でブックマークレットを実行し、別タブ(`blob:https://tetr.io/…`)にオフライン版を開く。AI は入らない |
| TETR.IO tools(ブックマークレット) | 盤面回転、リプレイ盤面修正+スピンカウンター【2026-11-08〜09】 |

- デスクトップ版は Mac(.command)・Windows(.cmd)・Linux(.sh)の起動ファイルで入れます。入れる前に TETR.IO を完全に終了してください(Mac は ⌘Q)。
- Mac はターミナルで `sh ~/Downloads/tetrio-patch-Mac-vO4.8255.command` のように実行します(ダブルクリックだと macOS に止められます)。
- 本体を変えずに確認だけするときは、最後に `--dry-run` を付けます。
- 起動ファイルの名前は `tetrio-patch-<OS>-v<A/R/O><版>` です【v4.8212】。

## 2. オンラインの TETR.IO で使う機能(デスクトップ版)

### リプレイの演出【v4.80】
- TL・ルームのリプレイ(TTRM)を、本体と同じ 3, 2, 1, GO で始めます。録画にあった長い待ち時間は除きます。
- スコアは TETR.IO 本体のルームの審判スコア表示と TL のプレイヤー名を使います。BOT の試合で TR を作り出すことはしません。
- リプレイを開くときにキーを押していると、演出を選べます。
  - 何も押さない:本体のスコア表示
  - Z:スコア+TL のイントロ(GET READY・赤青のプレイヤーカード・VS・FT)
  - X:スコア+TL のイントロ+最後の崩壊演出と結果表(勝者・最終スコア、合計とラウンドごとの APM・PPS・VS、プレイヤーアイコン)
  - C:TL のスコア上昇・+1 の演出【v4.8215 の基準書に記載】
- FINISH のあと、変わったスコアの数字だけを 0.58 秒光らせます。次のラウンドは、負けた盤面が落ち切ってから始めます。
- リプレイのヘッダーとタイムラインは Ctrl を押している間だけ出ます。本体の操作やショートカットはそのまま使えます。
- オンラインの LIVE 観戦は、ほかのプレイヤーの QP HYPERSPEED やリプレイ演出の状態から切り離します。
- TL イントロの GET READY の部分だけを短くし、赤青のプレイヤー表示は残します【v4.8212】。

### リプレイのファイル名【v4.11】
- 本体の TTR・TTRM のダウンロードは、モード・時刻・ID・内容から作った、同じ試合なら同じになるファイル名にします。ルーム名は使いません。

### Ctrl のリプレイバー【v4.8212】
- 40L・BLITZ・QP・TL のリプレイと、オフラインで遊んでいる最中のゲームで、Ctrl を押すと本体のリプレイバー(一時停止・速度)を出し入れします。メニューやオンラインのライブ盤面には出ません。

### ZEN の保存スロットの分離【v4.8212】
- ONLINE と OFFLINE で ZEN の保存スロットを分けます。互いのスロットは見えず、読み書きもできません。

### カスタムルームの盤面回転(ROTATO)【v4.8212】
- オンラインのカスタムルームのチャットで `/rotate` または `/rotato` を使います。TETRA LEAGUE と QUICK PLAY では使えません。
- コマンド:`/rotate`(180°の切り替え)、`/rotate 45`(角度を固定)、`/rotate random`(ランダムな角度)、`/rotate spin 90`(毎秒90°で回し続ける)、`/rotate random continuous 1.6`(1.6秒ごとにランダムな角度へ)、`/rotate reset`(0°に戻す)。
- 最初の解放には、`Y_KEI1215` と対戦していることが必要です(観戦だけでは解放されません)。
- ルームでの回転の共有は、ルームマスターが公式の START を押すか `/start` を実行したときに1回だけ送ります。内容は SHA-256 で確かめます。パッチを入れた人の画面では、パッチ同士のやりとりのメッセージを隠します。
- プレイ中は自分の盤面だけが回ります。解放済みの人が観戦すると、表示中の盤面すべてに回転を当てます。
- `/setting save 名前`・`/setting set 名前`(`/setting-save`・`/setting-set` でも可)で、ルームの設定を保存・適用します。

### QP PATCH TOOLS(CONFIG の一番下)
- QP のツールの一時停止・再開と、パッチの削除をまとめて置いています【v4.80】。一時停止しても設定は残ります。
- **REPLAY BOARD EDIT(ON/OFF、最初は OFF)**【v4.8234】
  - リプレイを一時停止すると、その場面から自分で操作できます(再生すると元に戻ります)。
  - スピンカウンター(SPIN・T-SPIN・QUAD)を表示します。
  - ON の間は、パッチのリプレイ演出(背景・シークバー非表示・Z/X/C・TL 演出・結果画面)と、次のラウンドの自動再生を切ります。名前はそのまま出ます。
  - QP TOOLS を一時停止していても動きます【v4.8236】。
  - TETRA CHANNEL を開いたとき、またはリプレイを読み込んだときに動き始めます【v4.8236】。どちらでもなくなったときや HOME に戻ったときは止まります【v4.8237】。
  - 操作している盤面が右にあれば左へ持ってきます。同じ2人のリプレイの間は、その並びを保ちます【v4.8237】。

### パッチの更新(PATCH UPDATE)【v4.8241、v4.8242 で修正】
- CONFIG の一番下「QP PATCH TOOLS」に「PATCH UPDATE」があります。オフライン画面では、Tab パネルの「パッチを更新」です。
- 新しいパッチがあれば「v4.xxxx に更新できます」と出ます。押すと、Web から今の OS と今の種類(A・R・O。A を使っていれば A のまま)の起動ファイルを取ってきて確かめ、TETR.IO を終了して入れ替え、自動で起動し直します。
- 最新のときは「最新です」と出るだけで、押しても何もしません。
- O・A は、素材の TETRIO-Resources-1.0.zip が「ダウンロード」(または ダウンロード/all-tetrio-patch)にあることが必要です。取ってきた起動ファイルは、その zip と同じフォルダに置きます。
- 更新が完了しなかったときは、TETR.IO を起動し直し、次に確認したときにその理由を表示します【v4.8244】。Windows で更新に失敗する問題は v4.8244 で直しました(v4.8243 以前からは一度手で入れてください)。
- v4.8241 は通信の不具合でアプリの中から更新できません。v4.8242 を一度手で入れると、そのあとはアプリの中で更新できます。

### 今の TETR.IO への対応
- 2026-11-09 の TETR.IO 更新(内部の名前の付け替え)に合わせています【v4.8235】。

## 3. オフライン(デスクトップ版 O・A、ブラウザ版 QP OFFLINE)

### 起動と画面
- オフラインのときは、自動で LOCAL に切り替わります。オンラインの HOME に足す項目は OFFLINE の1つだけです【v4.80】。
- 素材を内蔵した OFFLINE を使えます。Chrome 版では、TETR.IO に限って広告の非表示と配信先のブロックも行います【v4.80】。
- **Tab** で、オフライン用のパネルを開閉します。
- 描画診断と UI の状態の報告があります。起動やリプレイの保存に失敗したときは、黙って失敗せずに表示します。
- 描画停止の切り替えと、描画 FPS の上限を設定できます。

### 遊べるモード
- ローカルのソロ(40L・BLITZ など)、ZEN(保存スロット付き)、QP OFFLINE とリバイブ(復活)練習、TL・CUSTOM の FT 戦、ルーム設定の保存、カスタムラベル、受ける攻撃の設定。
- ゲーム時間の速度を変えられます。

### QP OFFLINE の設定
- 受ける攻撃:攻撃なし/定期攻撃/高層ほど強い攻撃。攻撃段数と攻撃間隔(ゲーム内の秒)を設定できます。
- 復活ミッション:標準のみ/自作のみ/すべて表示。
- 攻撃なしでも、攻撃が必要なミッションを表示する設定。
- 追加の操作系ペナルティを有効にする設定(ミッションごとの盤面回転とは別です)。
- リバイブラン:MOD の複数同時起動。
- MOD 中も条件を満たせば HYPERSPEED を許可する設定。
- 復活ミッションのテスト:1〜3番目に出すミッションを固定できます。
- リプレイの表示設定:QP リプレイの背景、TL イントロ、TL スコア上昇。

### リバイブ(復活)練習
- DUO の相方(LOCAL PARTNER)の盤面で、復活ミッションの練習ができます。
- 相方が戦闘不能の間は、BOT の盤面だけを 45% の不透明度にします(復活すると戻ります)【v4.8212】。
- ミッションが盤面の回転を求めるときは、DUO の相手の盤面も自動で回します。

### ローカルリプレイ
- ローカルのゲームを保存できます。一覧は新しい順・古い順・モード別に並べ替えられます。
- ローカルのリプレイファイルと、公式の認証済みのリプレイ記録を読み込めます。読み込むと、まず本体の記録・結果画面を開きます(すぐには再生しません)。
- 2人のリプレイは、通常の TL・カスタムルームの位置で表示します。
- ローカルの .ttr と、結合した .ttrm を書き出すボタンがあります【v4.11】。

## 4. 復活ミッション(QP OFFLINE のリバイブ)

ミッションは JSON で、端末の中に保存します(サーバーには送りません)。作成と編集はミッションエディタで行い、ゲームでは「自作ミッションを管理」「ミッションJSONを読み込む」「詳細エディタを開く」から使います。

### 達成条件
- 基本:ミノを置く、操作ミノの最下部の高さ、ラインを消す、スピンする、火力を送る、生存する、ゲーム画面を見ていない【v4.8233】、コンボ、Quad、B2B、回転する。
- そのほか、公式の復活ミッションの ID(T-Spin 系、Spin 系、HOLD 系、消し方の条件など)も使えます。
- 目標回数、制限時間(0 で無制限)、制限時間の数え始め(ミッションが出た時/最初にラインを消した時)。

### 詳しい条件(基本タブ)
- 対象のミノ(複数選択)、最後の向き、HOLD を使ってから、基準の列の範囲、設置時の最下部の高さ。
- Spin の種類(Any・通常・Mini・空 Spin)、1回に消すライン数(ちょうど・以上・以下)。
- 回転の制限(180°のみ/左右回転のみ)、ソフトドロップ(押し続ける/禁止)、左右入力を押し続ける条件。
- 進捗を 0 に戻すキー(複数)、追加条件を満たさなかったら進捗を 0 に戻す設定【v4.8231】。
- 失敗の判定に使うイベントの ID。
- 制限時間が切れたら、進捗を 0 に戻して最初から再挑戦します【v4.8231】。

### ルール・見え方・出現条件
- MOD をミッション中だけ適用(通常・リバース。同じ MOD の通常とリバースは同時に選べません)。MOD の効果を切って名前だけにすることもできます。
- HOLD 欄の表示、HOLD の中身の表示、HOLD 操作の可否。回転音を鳴らすかどうか。
- 左右操作の反転、回転操作(CW/CCW)の反転【v4.8231】。
- プレイヤーの盤面の回転(固定角度/ランダム、演出の長さ)。180°では左右・回転の入力も自動で反転します。
- 画面効果:縦分割(左右5列ずつ)・横分割(上下10段ずつ)・ゆっくり周回【v4.8231】、4分割【v4.8233】。分割は盤面の中心を画面中央に置きます。周回は約25秒で1周【v4.8231】。
- NEXT の表示・個数(0〜6)・隠す位置、操作中になった時に隠す位置、NEXT 1〜6番目の個別の見え方。
- 見え方(通常・非表示・点滅・徐々に表示・一部だけ表示):自分が置いたミノ、お邪魔ブロック、操作中のミノ、ゴースト、NEXT 欄、HOLD 欄。
- 出現条件:フロアの範囲、復活回数の範囲、必要な MOD・禁止する MOD。
- ランク:自動(通常ミッションの抽選ランクに合わせる。MOD があれば A)か、F〜A を固定。固定したランクは、MOD があっても変わりません【v4.8239】。
- ミッションが終わると、画面効果・回転・入力の設定を元に戻します【v4.8231】。

### 追加効果(エディタの「追加効果」タブ)【v4.8238】
複数を同時に使えます。ミッションが出た時に発動します。
- **盤面にブロックを置く**:盤面と同じマス目で描いた位置の空きマスにブロックを置きます(せり上がりなし)【v4.8239】。
- **消せない段**:追加・削除。N秒ごと/Nミノごとの繰り返しもできます。
- **強制ゴミ**(1ミッションに6件まで)
  - 付け方(複数可):即時上昇/地形変更(下から N 段を書き換え)/地形変更(今あるゴミ段の穴だけ変更)/ゴミ予測バーに付与。
  - 地形:指定なし(本体のランダム)、またはシード由来の1つ穴・2つ穴・2列の交互配置・市松模様・固定の列・特定の形(TSD・TST・縦4段・階段・ジグザグ)・テンプレート。
  - シード:ゲームのシード由来か固定の数値。同じシードなら同じ並びになります。
  - ボム:穴の代わりにボムを置きます。ボムの上にミノを置くと、その段が消えます。ボムは本体のボムの見た目で、消せない段は元の見た目のままです(デスクトップのオフライン版はボムの画像がないので、色付きのマスで表示します)。
  - テンプレートは盤面と同じマス目で描けます。押したままなぞると、続けて置く・消すことができます。ひな形(TSD・TST)もあります。上下の空の段は詰め、ゲーム中は盤面の高さに収まるように使います【v4.8239】。
  - 形・テンプレートを選ぶと、付け方は「即時上昇」になります【v4.8239】。
  - 発動するとき:ミッション開始時(繰り返しも可)か、ゴミ(攻撃)を受けた時【v4.8239】。
- **盤面の大きさ**:高さ(4〜40段)と横幅(4〜20列【v4.8241】)。HOLD・NEXT も作り直して表示を保ちます。穴の列・テンプレート・ブロックを置くマス目も、その大きさになります。
- **操作感度**【v4.8241】:DAS(1〜20)・ARR(0〜5)・SDF(5〜41。41 は即時)・DCD(0〜20)のうち、変えたいものだけを選んで変えます(例:DAS だけ、ARR だけ)。
- **直列率**:攻撃が変わっても穴が同じ列のままの率と、1回の攻撃の中で穴がそろう率。
- **Spin ルール**:T-spins・T-spins+・all-mini+(QP 標準)・all-mini・all・all+・mini-only・T/S/Z/L/J のみ・stupid・なし。MOD の Spin ルールより優先します。
- **ミノの増減**:I/O/T/S/Z/J/L を1袋あたり −1〜+4、I5 ミノを1袋あたり 0〜4個。次に作られる袋から反映します。
- 盤面の大きさ・操作感度・直列率・Spin ルール・ミノの増減は、戻すタイミングを「ミッション終了時/復活し終えた時/ラン中」から選べます。MOD の変更は、必ずミッション終了時に戻ります。

### 失敗・達成時の設定【v4.8239】
- 時間切れで即死、リセット判定で即死(進捗を 0 に戻すキー・条件の不一致・B2B が切れた時など)。
- 達成時に伸ばす距離(0〜1000m)、達成時に送る火力(0〜1000。実際に攻撃したのと同じ扱い)。

### 洗濯機ミッション【v4.8239】
- 「回転」のミッションで、数えるミノを選べます(例:J と L)。
- 洗濯機:同じ向きに4回回して元の位置・向きに戻り、ミノの 3×3 の枠の中にブロックがある時に1周と数えます。
- エディタの「洗濯機ミッションを追加」で、中央にブロックを1つ置いた、J/L で1周のミッションを作れます。

### 本体の進み方への対応【v4.8239】
- B2B のミッションは、本体の「B2B の値まで引き上げる」処理で進みます。B2B が切れると 0 に戻ります。

## 5. HYPERSPEED

- 裏 MOD を含む状態で HYPERSPEED がオンになると、「Kugelhagel OVERDRIVE」をループ再生します(3:08.499583 でループ)。通常の MOD の HYPERSPEED は従来の曲です。HYPERSPEED を抜けると通常の階層曲に戻ります。音量はゲームの BGM 音量に従います【v4.8232】。
- 曲は本体に内蔵します【v4.8232】。ブラウザ版はサイトに置いた曲を読みます【v4.8239】。
- 曲の再生を始める命令を1回にして、ラグを直しました。曲を切り替える2つの処理が食い違っても、行き来しません【v4.8239】。
- リザルト画面では、表・裏とも HYPER の演出・曲・拍の音を止めます。ゲームが終わった時の HYPER 終了音も鳴らしません(オンライン用ではこの終了音は本体のまま)【v4.8239】。
- オンライン用の書き換え(リプレイ・観戦の表示)にも、同じ修正を当てています【v4.8239】。

## 6. ミッションエディタ

- **v5.3**:QP 共通の条件を基本タブにまとめた版。v6 系でも、この設定項目をすべて維持しています。
- **v6.0**:Offline QP 用のエディタ。
- **v6.1**:画面効果(縦分割・横分割・周回)、操作反転、進捗リセットを設定【v4.8231】。
- **v6.2**:フロアの範囲を通常の1〜10Fに変更。古い JSON の 11F 以上は 10F に丸めます【v4.8232】。
- **v6.3**【v4.8233】・**v6.4**:4分割の画面効果、「ゲーム画面を見ていない」の条件など。
- **v6.5**【v4.8238】:「追加効果」タブ(上の追加効果のすべて)。v4.8239 で、即死・距離・火力、テンプレートと「ブロックを置く」のマス目(なぞって置く・消す)、洗濯機ミッション、回転ミッションの対象ミノを追加しました。

## 8. AI 版(デスクトップ版 A)【v4.80】

- 回転ルールの認識、BOT 専用の Spin の探索量、CUSTOM の空ラベルの復元。

- Spin の探索【v4.11】:向き・合法なキック・HOLD を含めて事前に候補を数えます。実際の回転と消去はゲーム本体が判定します。

- T が HOLD か NEXT にあるときは、T 穴の屋根を作る置き方を「穴」として減点しません。盤面の上半分まで積んでいるときは安全を優先します。深い溝を2本作る置き方は避けます【v4.8245】。
- プレイヤーの回転入れが多いほど、AI も回転入れで消す手を重く見ます。ミニの Spin は軽く見ます【v4.8245】。
- 左右移動【v4.8245】:同じ方向に2マス以上動くときは、キーを押し続けて DAS/ARR で動かします(壁まで動くとき、または ARR が1フレーム以上のとき)。ARR が 0 で途中の列に止めるときは、押し続けると壁まで滑るので連打で動かします。ソフトドロップも床まで押し続けてから離します。
- Spin B2B モード【v4.8248】:ソロ(QP・40L など)で BOT が Spin だけで B2B をつなぎます。既定で ON です(QP 設定の「vAI テスト設定」で切り替え)。TL・CUSTOM の2人対戦と、攻撃が来ている間は通常の判断です。
- Spin B2B モードの先読み【v4.8248】:CURRENT・HOLD・NEXT を使って6手先まで読み、T-Spin を多めに、ほかのミノの Spin(Double・Triple を優先)と、端の溝を使った Quad を少し混ぜます。T-Spin mini は T の無駄使いとして軽く見ます。置き場所・キック・Spin の判定はゲーム本体と同じ規則で、選んだ手はゲーム本体の中で一度置いて確かめてから打ちます。

- 型(組み方)の学習【v4.8254】:Spin・Quad で消すまでの数手の組み方を「型」として、自分の TTR・TTRM(指定した選手、空欄なら勝った方のラウンド)・自分のプレイから最大 2500 種類覚えます。BOT は盤面とミノ順(CURRENT・HOLD・NEXT)に合う型を優先します。QP 設定の「自分の TTR から Spin・型・好みを取り込む」で複数まとめて選べます。

- 火力の計算【v4.8254】:消去ごとの実際の火力(B2B、コンボの倍率)と B2B チャージ(B2B 5 以上で切ると B2B−1 段)を計算します。いつも切る長さ(既定 50)でチャージを使い、「B2B を切る → コンボで掘る → Spin / Quad で締める」流れも評価します。

## 9. TETR.IO tools のブックマークレット

### 盤面回転【2026-11-08】
- ゲームが Spin と判定したとき(画面に「X-spin」と出たとき。Mini も含む)に、盤面を指定した角度だけ回します。
- 回す向きは、プレイヤーが最後に押した回転キーで決めます。180°回転の Spin は、180°と360°を交互に回します。
- 盤面ごとに、10×20 の盤面の中心で回します。リプレイやルームでも使えます。
- 30秒ごとに自動で更新します。パネルを閉じても、小さな「盤面回転」ボタンが残ります。

### リプレイ盤面修正+スピンカウンター【2026-11-08〜09】
- リプレイを止めると、その場面から操作できます。再生や R で止めた場面に戻ります。Ctrl+Z・Ctrl+Y で1ミノずつ取り消し・やり直しができます。
- トップアウトしたら、致命的なミノの前に戻ります。重力なしの切り替えがあります。
- 矢印キー・スペースはリプレイのショートカットに渡しません。攻撃は表示だけで、送りません。
- 編集を fumen で書き出します(1ミノ1ページ。ライン消去は消す前のページも出します)。
- fumen の書き出し方を選べます【2026-11-09、パッチ版は v4.8243】:ページ(1ミノごと/7ミノごと)、色(そのまま/その巡で置いたミノ以外グレー/最後に置いたミノ以外グレー)。巡はゲームの最初から数え、止める前に同じ巡で置いたミノも、再生中の記録から色分けします。1巡(7ミノ)ごとのページでは、巡の中で消したラインを埋まった段のまま残し、次のページで消します【v4.8244】。
- 2人の左右を入れ替えられます。操作している盤面を左に置きます。
- スピンカウンター:SPIN(消したライン数/ミノ数)、T-SPIN(Mini を含む回数/置いた T の数)、QUAD。リプレイでは、本体の事前計算から今のフレームまでを数えるので、シークしても正しく数えます。

## 12. オフラインの対戦と Tab パネルの設定【v4.8276〜v4.8281】

オフライン画面で Tab を押すと開くパネルです。パネルには短い名前だけを出し、説明はここに書きます。「vAI 設定」は閉じた状態で開きます【v4.8281】。

### オフライン専用設定・ゲーム速度(最初はすべて OFF。オンにした設定はバージョンアップ後もそのまま)【v4.8280〜v4.8281】
- **警告音**:積みが高くなったときの警告音。
- **警告ミノ**:次に出るミノが置けないとき、出現位置にミノの形を表示します。
- **せり上がり予告線**:次にゴミが上がったときの積みの上端を、盤面より上にはみ出す部分だけ赤い線で表示します(操作ミノより後ろ)。盤面より上にすでにブロックがあるときは出しません。
- **TL点数の+1演出**:TL・CUSTOM 対戦で、盤面の上の点数が上がるときに「+1」を出します。点数そのものは常に表示します。
- **TL勝敗後の点数画面**:ラウンドが終わるとボードを消して、本物の TL と同じ点数画面を出します。次のラウンドは約6秒後に始まります。
- **TLの曲**:TL・CUSTOM 対戦で、オンラインの TL と同じくバトル曲からランダムに1曲流します。ラウンドをまたいで続き、試合が終わるか「終了」で止まります。音楽の音量が0のときは流しません。
- 2ラウンド目以降は、開始時の演出(LOCAL TETRA LEAGUE の表示)と音を出しません。
- プレイ中も、盤面の上でマウスホイールを回すと音量を変えられます(本体と同じ動き)。
- リプレイ中の C キーは、ホールドなど本来の操作に使われます(点数演出の切り替えは削除しました)。

### vAI 設定(A のみ)
- **BOT: Spin B2B モード**(既定 ON):QP・40L・TL・CUSTOM で、T-Spin 多めの Spin だけで B2B をつなぎます。攻撃が来たら、相殺するか受けるかを高さで決めます。
- **勝率予測ゲージ**(既定 ON):TL・CUSTOM で、盤面から左右の勝率を予測して上に表示します。
- **プレーヤーと同時に置く**(既定 OFF):TL・CUSTOM の対プレーヤー戦で、プレーヤーが1つ置くたびに BOT も1つ置き、PPS を揃えます。
- **同時に置く比 プレーヤー:BOT**(既定 1:1):例 10:9 で BOT が1割少なく置きます【v4.8279】。
- **置きミスを再現**(既定 OFF):ときどき1列ずれて置きます。悪い手として扱い、学習や修正ツールの指摘には使いません。
- **BOT目標PPS**:0.1〜20。ゲーム内時間が基準です。
- **計算量**:自動(既定)は PC の速さを測り、目標 PPS に合わせます。低は軽い PC 向け、最大は速い PC 向けです。BOT が動くと計画速度を測って表示します。
- **配置予測の表示・予測情報**:プレイヤーの実際の Spin 直前の構造から、壁・屋根と後続の回転候補を1案ずつ描きます(最大5案切替)。同じミノの配置違いで候補を埋めず、CURRENT/HOLD/NEXT で確定した2手と将来構想を区別します。Spin 成功の保証はありません。学習データがなければ表示しません。
- **TTRから型を取り込む**:自分の TTR から Spin・型(組み方)・好みを取り込みます。自分のプレイ中も保存します。BOT はミノ順と盤面に合う型を優先します。
- 保存AI・相方AI・攻撃設定は、AI管理の「プレイ・対戦」にあります。vO にはこの項目を表示しません。

### 外部AI対戦(A のみ)【v4.8276〜】
- 外部AIはパッチに入っていません。自分のパソコンにある外部AIのファイル(.js と、必要なら .wasm など)を「外部AIを読み込む」で選びます。外部AIは別スレッド(Worker)で動き、外部AIの試合は学習に記録しません。
- **FT**:先に何本取ったら勝ちか。**外部AIの強さ**:エンジンごとの探索量(空欄で既定)。
