コードを手動でコピーする

ほかの取得・追加方法

PCブラウザ

「コードをコピー」→ ブックマークを1つ作成 → URL 欄を貼り替えます。Chrome、Edge、Firefox、Safari に対応します。

iPhone / iPad

Safari で任意のページをブックマークしてから、編集画面の URL 欄をコピーしたコードで置き換えます。ポップアップが止められたら TETR.IO のポップアップを許可してください。

Android

Chrome 等でブックマークを作成し、編集画面の URL 欄をコードへ置き換えます。アドレスバーにブックマーク名を入力して実行します。OS 版を使う場合は下の OS 別パッチを選びます。

OS別パッチ

使用中の OS と、必要な形式を選んでください。O と R はすぐにダウンロードできます。実行前に TETR.IO を完全に終了(Mac は ⌘Q)してください。

macOS

O形式をダウンロードR形式をダウンロードA形式をダウンロード

Windows

O形式をダウンロードR形式をダウンロードA形式をダウンロード

Linux

O形式をダウンロードR形式をダウンロードA形式をダウンロード

実行のしかた: Mac はターミナルで sh ~/Downloads/tetrio-patch-Mac-vO4.8242.command(ダブルクリックだと権限で止まります)。Windows は .cmd をダブルクリック。Linux は sh tetrio-patch-Linux-vO4.8242.sh。本体を変えずに確認だけするときは最後に --dry-run を付けます。SHA256 一覧

O形式・A形式には TETRIO-Resources-1.0.zip(TETR.IO の素材。Discord で配布)が必要です。起動ファイルと同じフォルダ、その一つ上、または「ダウンロード」フォルダに置いてください。R形式は不要です。

A形式の Discord 認証

A形式(AI 版)を選ぶと、Discord のログイン画面を開きます。指定の Discord サーバーでロールを持っていることを確かめたあと、ダウンロードできます。

パッチの更新(PATCH UPDATE)

v4.8242 から、CONFIG の一番下「QP PATCH TOOLS」の PATCH UPDATE(オフライン画面では Tab パネルの「パッチを更新」)で、新しいパッチに入れ替えられます。押すと、今の OS と今の種類(A・R・O)のパッチを取ってきて、TETR.IO を終了して入れ替え、自動で起動し直します。最新のときは何もしません。

O・A は、TETRIO-Resources-1.0.zip が「ダウンロード」(または ダウンロード/all-tetrio-patch)にあることが必要です。

リバイブミッションの追加効果(v4.8238〜)

ミッションエディタ v6.5 の「追加効果」タブで設定します。複数を同時に使えます。

  • 消せない段の追加・削除(開始時と、N秒ごと/Nミノごとの繰り返し)。
  • 強制ゴミ:即時上昇・地形変更(下からN段を書き換え/今あるゴミ段の穴だけ変更)・ゴミ予測バーに付与。地形指定なし、またはシード由来のパターン(1つ穴・2つ穴・2列の交互配置・市松模様・固定の列・特定の形・テンプレート)。ボムにもできます。
  • 盤面の高さ、直列率(攻撃間・攻撃内)、Spinルール、ミノの増減、I5ミノ。戻すタイミングは「ミッション終了時/復活し終えた時/ラン中」から選べます。MOD の変更はミッション終了時に必ず戻ります。

REPLAY BOARD EDIT(パッチ版の盤面修正)

CONFIG の一番下「QP PATCH TOOLS」の REPLAY BOARD EDIT: ON/OFF で使います(最初は OFF)。ON にすると、リプレイ盤面修正と同じく、リプレイを止めるとその場面から操作でき、スピンカウンターも出ます。

  • 動き始めるのは、TETRA CHANNEL を開いたとき、またはリプレイを読み込んだとき。どちらでもなくなったときや HOME に戻ったときは止まります(操作中なら止めた場面に戻ります)。
  • QP TOOLS を PAUSED にしていても動きます。
  • ON の間は、パッチのリプレイ演出(背景変更・シークバー非表示・Z/X/C の演出切り替え・TL 演出・結果画面)と、次のラウンドの自動再生を切ります。名前はそのまま出ます。
