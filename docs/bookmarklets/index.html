下のボタンをブックマークバーへドラッグしてください。https://tetr.io/ を開いてボタンを押すと、別タブにOFFLINEを起動します。

ブラウザ版は追加のインストール不要です。QP、ZEN、ローカル／オンラインリプレイ、端末内保存、OFFLINE盤面回転を利用できます。通常のオンライン対戦・ルーム・観戦は起動しません。

localhostは使用していません。blob:https://tetr.io/… の一時ページで動きます。OFFLINE用の接続先はGitHubリポジトリで、起動時だけ公式TETR.IOの画面素材と本体を読み込み、プレイはOFFLINE内で行います。

iPhone／iPad（Safari）

  1. このページを普通のブックマークとして一度保存します。
  2. 上の「ブックマークコードをコピー」を押します。
  3. Safariのブックマーク編集を開き、保存したブックマークのURLを全削除してコードを貼り付けます。
  4. https://tetr.io/を開き、ブックマーク一覧から実行します。

iOS版ChromeよりSafariを推奨します。ポップアップが止められた場合はTETR.IOのポップアップを許可してください。

Android（Chrome）

  1. このページをブックマークし、名前を「TETR.IO OFFLINE」に変更します。
  2. コードをコピーし、ブックマーク編集画面のURLへ貼り付けて保存します。
  3. https://tetr.io/を開き、アドレスバーへ「TETR.IO OFFLINE」と入力して、候補に出るブックマークを選びます。

デスクトップ版(Mac／Windows／Linux)のパッチ v4.8235

ブラウザではなく、TETR.IO デスクトップアプリに入れる版です。実行前に TETR.IO を終了してください。ファイルは GitHub のリリースに置いています(SHA256SUMS)。

  • vA(AI版): OFFLINE／保存／Replay に加えて AI ― Discord でログインして取得(指定の Discord サーバーのロールが必要)
  • vO(OFFLINE版): OFFLINE／保存／Replay ― Mac ・ Windows ・ Linux
  • vR(Replay版): 通常の TETR.IO に Replay 表示だけ追加する軽量版 ― Mac ・ Windows ・ Linux

Mac: ダウンロード後、ターミナルで sh ~/Downloads/tetrio-patch-Mac-vR4.8235.command のように実行します(ダブルクリックだと実行権限や警告で止まることがあります)。
Windows: .cmd をダブルクリック。Linux: sh tetrio-patch-Linux-vR4.8235.sh。
本体を変えずに確認だけしたいときは、最後に --dry-run を付けます。

vA・vO には、別に TETRIO-Resources-1.0.zip(TETR.IO の素材)が必要です。起動ファイルと同じフォルダ、その一つ上、または「ダウンロード」フォルダに置いてください。TETRIO-Resources-1.0.zip は Discord で配布しています(このサイトにはありません)。vR は不要です。

v4.8234〜 の新機能: REPLAY BOARD EDIT

CONFIG の一番下「QP PATCH TOOLS」に REPLAY BOARD EDIT: ON/OFF を追加しました(最初は OFF)。ON にすると、ブラウザ版のリプレイ盤面修正と同じく、リプレイを止めるとその場面から操作でき、スピンカウンターも出ます。パッチ版はゲームを最初からつかまえるので、「リプレイを開く前に押す」必要はありません。

  • ON の間は、パッチのリプレイ演出(リプレイ背景の変更・シークバーを隠す・Z/X/C の演出切り替え・TL の導入やスコア演出・最後の結果画面)と、次のラウンドの自動再生を切ります。プレイヤーの名前はそのまま出ます。
  • QP TOOLS を PAUSED にしているときは動きません。

v4.8235 は、2026年11月9日の TETR.IO の更新(内部の名前の付け替え)に合わせた版です。v4.8233・v4.8234 は今の TETR.IO ではリプレイ演出・オフライン機能・CONFIG の停止/削除の項目が出ないので、v4.8235 を入れ直してください。
