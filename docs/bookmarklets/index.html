TETR.IO Standalone OFFLINE v4.8216

下のボタンをブックマークバーへドラッグしてください。https://tetr.io/ を開いてボタンを押すと、別タブにOFFLINEを起動します。

Loading bookmarklet...

ブラウザ版は追加のインストール不要です。QP、ZEN、ローカル／オンラインリプレイ、端末内保存、OFFLINE盤面回転を利用できます。通常のオンライン対戦・ルーム・観戦は起動しません。

localhostは使用していません。blob:https://tetr.io/… の一時ページで動きます。OFFLINE用の接続先はGitHubリポジトリで、起動時だけ公式TETR.IOの画面素材と本体を読み込み、プレイはOFFLINE内で行います。

iPhone／iPad（Safari）

  1. このページを普通のブックマークとして一度保存します。
  2. 上の「ブックマークコードをコピー」を押します。
  3. Safariのブックマーク編集を開き、保存したブックマークのURLを全削除してコードを貼り付けます。
  4. https://tetr.io/を開き、ブックマーク一覧から実行します。

iOS版ChromeよりSafariを推奨します。ポップアップが止められた場合はTETR.IOのポップアップを許可してください。

Android（Chrome）

  1. このページをブックマークし、名前を「TETR.IO OFFLINE」に変更します。
  2. コードをコピーし、ブックマーク編集画面のURLへ貼り付けて保存します。
  3. https://tetr.io/を開き、アドレスバーへ「TETR.IO OFFLINE」と入力して、候補に出るブックマークを選びます。

デスクトップ版(Mac／Windows／Linux)のパッチ v4.8217

ブラウザではなく、TETR.IO デスクトップアプリに入れる版です。実行前に TETR.IO を終了してください。

  • vO(OFFLINE版): OFFLINE／保存／Replay ― Mac ・ Windows ・ Linux
  • vR(Replay版): 通常の TETR.IO に Replay 表示だけ追加する軽量版 ― Mac ・ Windows ・ Linux

Mac: ダウンロード後、ターミナルで sh ~/Downloads/tetrio-patch-Mac-vO4.8217.command を実行します(ダブルクリックだと実行権限や警告で止まることがあります)。
Windows: .cmd をダブルクリック。Linux: sh tetrio-patch-Linux-vO4.8217.sh。
