QP OFFLINE

QP PB ランキング

QP OFFLINE(パッチ・ブックマークレット)で出した記録のランキングです。1人1記録(各ランキングでいちばん高いもの)を高さ順に並べます。上位3人はリプレイを見られます。

登録のしかた: オフライン(アプリ版・ブラウザ版)の記録一覧で、記録の「ランキングに送る」を押します。確認のあと、記録とリプレイがそのまま送られ、10〜30分ほどで載ります(アカウントは要りません)。送れないときは GitHub の登録ページが開くので、保存されたリプレイ(.ttr.json)を「リプレイ」欄にドラッグして送ってください。記録は自己申告です。
