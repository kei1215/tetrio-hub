リプレイ盤面修正

盤面回転・QP OFFLINE とは別のブックマークレットです(スピンカウンターも、このブックマークで一緒に出ます)。公式の https://tetr.io/ のリプレイを一時停止すると、その場面から自分で操作できます。再生ボタンを押すと、止めたときの場面に戻ってからリプレイが続きます。使えるのはリプレイの中だけで、対戦中やルームの盤面には何もしません。

下のボタンをブックマークバーへドラッグしてください(このページでクリックしても動きません)。

使い方(PC)

  1. https://tetr.io/ を開き、リプレイを開く前にブックマークをクリックします(左上に「リプレイ盤面修正」のパネルが出ます)。
  2. リプレイを開きます。すでに開いていたときは、一度閉じて開き直してください。押したあとに開いたリプレイが対象です。
  3. リプレイを一時停止します。パネルが「操作中」になり、その場面の盤面・操作中のミノ・HOLD・NEXT のまま、ふだんのキー設定(TETR.IO の設定どおり)で操作できます。DAS・ARR などのハンドリングも自分の設定です。
  4. 再生ボタンを押すと、止めた場面に戻ってからリプレイが続きます。シークバーやフレーム送りで移動したときも、元の状態に戻ります。
  • 操作中は、キー設定で使っているキーを TETR.IO のリプレイ操作に渡しません。左右キーでシークバーが動いたり、スペース(ハードドロップ)で再生が始まったりはしません。再生はマウスで再生ボタンを押してください。
  • リトライのキー(R)か、パネルの「止めた場面からやり直す」で、止めた場面から何度でもやり直せます。積み上がって終わったときも、少しして止めた場面に戻ります。
  • 操作中の火力はパネルに表示しますが、相手には送りません(相手の盤面は止まったままです)。
  • 2人のリプレイでは、パネルの「操作する盤面」で左右を切り替えます。
  • 「2人の左右を入れ替え: ON」にすると、2人のリプレイで左右のプレイヤーの位置が入れ替わります(見た目だけ。止めていなくても使えます)。
  • 「止めたら操作: OFF」にすると、止めてもふつうのリプレイのままです。
  • 「重力: なし」にすると、操作中のミノが自然には落ちません(ソフトドロップ・ハードドロップで落とします)。
  • 操作中のままリプレイを閉じても大丈夫です(止めた場面に戻してから閉じます)。

修正を .ttrm に埋め込んで保存

止めて動かしたあと、パネルの「修正を .ttrm に埋め込んで保存」を押すと、TETR.IO のリプレイ(.ttrm / .ttr)に修正を入れたファイル(名前の最後が -edit)を保存します。

  • このブックマーク(またはデスクトップ版パッチの REPLAY BOARD EDIT)が入っていると、そのファイルは修正後の内容で再生されます。止めた場面までは元のリプレイ、そこからは自分の操作です。操作の最後まで来ると、その盤面は止まります。修正の後ろへシークしても、修正後の盤面になります。
  • 入っていない TETR.IO では、ふつうの(元の)リプレイとして再生されます。修正は各プレイヤーの記録の結果欄に足すだけで、TETR.IO のリプレイの形は変えません。
  • 保存すると、今開いているリプレイもすぐ修正後で再生されます。元に戻すときは「埋め込みを外す」を押します。
  • 埋め込みのあるリプレイを修正の途中で止めて直すと、前の修正の続きとして1つにまとまります。
  • 修正が元のリプレイより長いときは、元のリプレイの長さまでしか再生されません。

地形のマネ練習

「マネ練習: ON」にして止めると、リプレイで実際に置いた所が、ゴーストとは別に光る「目標のミノ」で出ます。

  • 目標と同じ所に置くと、次の手の目標に進みます。違う所に置くと、少し見せてから置く前に戻ります。
  • 手本は止めた場面から最大80手(または約0.4秒で作れる分)です。HOLD を使った手本は、HOLD してから置きます。
  • 手本のプレイヤーがゴミを受けて地形がせり上がった分は、ずらして合わせます。
  • 「重力: なし」と組み合わせると、ゆっくり形を確かめられます。

更新は自動です。30秒ごとに新しい版を確かめ、出ていれば読み込み直します(操作中は待ちます)。

fumen に書き出す

パネルのボタンで、連続テト譜エディタ(fumen)を新しいタブで開きます。

  • 操作中:「fumen に書き出す」。1ページ目が止めた場面、2ページ目からはミノを1つ置くごとの地形です(1ミノ1ページ)。ラインを消したミノは、まず置いた所(そろったラインが残った地形)を1ページ出し、次のページで消えた後の地形を出します。Ctrl+Z で取り消したミノは入りません。
  • 操作していないとき:「fumen で今の盤面を開く」。今の盤面を1ページで開きます。

入るのは地形だけで、操作中のミノ・NEXT・HOLD は入りません。

スピンカウンター

同じブックマークで、右上に「スピンカウンター」のパネルも出ます(盤面修正のパネルの「スピンカウンター: ON/OFF」で表示/非表示)。盤面ごとに数え、表示だけでゲームには何もしません。リプレイだけでなく、SOLO・QP・TL・ルーム・観戦でも数えます(ブックマークを押したあとに始まったゲームが対象)。

SPINスピンの回数(T 以外のミノ・MINI も含む)。かっこ内は MINI の数
SPIN の列ごとスピンで消したライン数ごとの内訳(0列 / 1列 / 2列 / 3列)。カウンターのパネルのボタンで表示/非表示
ミノごとスピンをミノの種類ごとに(T・S・Z・L・J・I・O)。ボタンで表示/非表示
T-SPINT-spin の回数(MINI 含む) / 置いた T ミノの数と、その割合。MINI の数も出します
QUAD4ライン消しの回数
  • リプレイでは、開いたときに TETR.IO が裏でリプレイ全体を計算するのを見て「何フレーム目に何を置いたか」の一覧を作り、今のフレームまでの分を数えます。前に戻しても先へ飛ばしても正しい数になります。
  • 止めて操作した分は、再生して元に戻すと消えます。
  • ブックマークを押し直しても、数えた回数は消えません。

fumen に書き出す / fumen で今の盤面を開く操作中は止めた場面から1ミノごとのページで、操作していないときは今の盤面を、新しいタブの fumen で開きます
